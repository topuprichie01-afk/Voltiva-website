# Voltiva Full Website Starter (HTML/CSS/JS)

## Pages included
- `index.html` — homepage
- `signup.html` — sign-up page
- `login.html` — login page
- `dashboard.html` — customer dashboard preview
- `buy-data.html` — data order form
- `buy-airtime.html` — airtime order form
- `boosting.html` — boosting request form
- `styles.css` — shared responsive styling
- `app.js` — simple demo interactions

## Open it on an iPhone
Upload/extract these files in an online editor such as Replit, or use a static website host. Keep all files in the same project folder and open `index.html` in the preview.

## Important: demo only
These pages are the front-end layout. Sign-up and login are not secure authentication, dashboard data is sample data, and order forms do not save or submit real orders. Do not enter real passwords or customer information. Before launch, connect a secure authentication backend (for example Supabase Auth), database tables with row-level security, a trusted VTU API, and a payment gateway with server-side payment verification and webhook handling. Do not place secret keys in browser JavaScript.
